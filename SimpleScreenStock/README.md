# A股多条件组合选股（AKShare + SQLite + Streamlit）

基于本地 AKShare 的可复用 Python Web 应用：**首次运行全量拉取 A 股历史数据（日K线、PE-TTM、PB-MRQ、
上市日期、所属板块、交易所、分红事件）存入本地 SQLite**，之后每次运行仅拉取**增量交易日**数据；
页面上 13 个量化条件可任意多选（"且"关系取交集），多条件通过 `ThreadPoolExecutor` **并行计算**，
结果表格中**股票名称为超链接**（新标签页打开同花顺个股页 `https://stockpage.10jqka.com.cn/代码/`，不显示原始URL），按 **PE-TTM 由低到高**排序。

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `maidenstart.bat` | **一键启动程序**：自动检查/安装依赖 → 启动服务 → 打开浏览器（支持 `install`/`stop` 参数） |
| `app.py` | Streamlit 界面：侧边栏配置区 + 条件多选 + 开始筛选 + 结果表格/CSV下载 |
| `stock_core.py` | 核心库（不依赖 Streamlit）：配置区、AKShare 数据获取、13个条件函数、增量同步、并行筛选 |
| `stock_db.py` | SQLite 存储层：建表/写入/读取/统计（WAL 模式，写锁+线程级只读连接） |
| `requirements.txt` | 依赖清单 |

## 安装与启动

### 方式一：一键启动（推荐）

双击 `maidenstart.bat`：自动检查/安装依赖 → 启动服务 → 打开浏览器 http://127.0.0.1:8501。
停止服务：关闭最小化控制台窗口或运行 `maidenstart stop`；仅装依赖：`maidenstart install`。

### 方式二：手动命令

```bash
pip install -r requirements.txt
streamlit run app.py
```

可选环境变量：`STOCK_DB_PATH`（数据库路径）、`STOCK_LIMIT`（调试限量）。

## 数据缓存与增量更新机制

### 先选范围，再拉数据（提速核心）

侧边栏「🎯 数据范围」可先选 **证券市场**（全部A股 / 深证 / 沪证 / 北证）和/或 **所属板块**
（申万一级行业，可多选）。**范围是同步与筛选的过滤器**：meta 表始终全量常驻（全部A股基础信息），
范围过滤纯本地计算、零网络请求：

| 范围示例 | 股票数 | 首次拉取耗时（参考） |
| --- | --- | --- |
| 全部A股 | ~5500 | 约10~20分钟 |
| 深证 / 沪证 | ~2800 / ~2300 | 约5~10分钟 |
| 北证 | ~300 | 约1分钟 |
| 单个板块（如"银行"） | ~42 | **秒级** |

- **大范围已抓取 → 小范围直接复用**：切换范围即时生效于筛选；同步时已缓存的数据自动跳过，绝不重复拉取；
- 侧边栏实时显示"当前范围股票数"；勾选"启动时自动增量更新"时修改范围自动触发一次同步；
- 同步内容开关：可单独关闭「估值PE/PB」「分红股息率」进一步提速（对应条件将无法命中，技术形态条件不受影响）；
- 加载过程进度条下方每5秒轮动一条金句（Dancing in roses / 做好人，买好股，得好报 / …）。

### 板块映射落盘缓存

申万行业成分（31个行业）抓取结果存入 SQLite（`sector_map`/`sector_boards` 表），
**一次抓取后跨进程、跨天复用**：重复启动时"准备基础数据"阶段从约40秒降至毫秒级；
且按板块范围选择时**只抓取所选行业的成分**（如仅选"银行"只发1个请求）。
「🔄 刷新板块映射」按钮可强制重抓（一般无需使用）。

### 增量更新

- **首次运行**：按所选范围全量拉取日K线（前复权，自上市日）、PE-TTM/PB-MRQ 历史（东财F10，约2018年至今）、
  分红事件（巨潮，新浪兜底）、上市日期（三大交易所官方列表）入库到 `stock_data.db`（路径可配），全程进度条展示。
- **后续运行**：只拉取**本地最新日期之后的增量交易日**数据追加入库（`INSERT OR REPLACE` 幂等）；
  估值/分红接口无日期参数，按**新鲜度策略**刷新（`VAL_REFRESH_DAYS`=3天 / `DIV_REFRESH_DAYS`=7天，侧边栏可调），仅追加新日期。
- **指标计算不受增量影响**：技术指标始终基于库中完整留存的历史数据计算。
- **强制全量刷新**：侧边栏勾选确认后点击「🗑️ 强制全量刷新」，**仅清空当前范围内**所选同步内容的数据并重新全量拉取（范围外缓存不受影响），用于应对数据异常。
- 侧边栏实时显示数据库状态（股票数、日K/估值行数、最新日期）；「🔄 增量更新数据」可手动触发同步。

## 13 个筛选条件（阈值全部侧边栏可调，默认值见 `stock_core.py` CONFIG 配置区）

| # | 条件 | 默认阈值 | 量化定义 |
| --- | --- | --- | --- |
| ① | 上升通道 | `CHANNEL_DAYS`=60, `CHANNEL_R2`=0.6 | 近60日收盘价线性回归斜率>0 且 R²≥0.6 |
| ② | 回踩支撑确认 | `PULLBACK_DAYS`=20, `SUPPORT_MA`=20, `PULLBACK_TOL`=2% | 近20日内最低价曾贴近20日均线（差值≤2%），且最近一日收盘价重新站上该均线 |
| ③ | 碎步小阳 | `SMALL_YANG_DAYS`=5, `SMALL_YANG_MAX`=3% | 近5个交易日连续阳线（收盘>开盘）且每日涨幅≤3% |
| ④ | 小步上扬W底 | `W_BOTTOM_DAYS`=60, `W_BOTTOM_TOL`=3% | 近60日内两个低点（最低点与次低点）价格差≤3%、间隔≥10个交易日，且当前价突破两低点间反弹高点 |
| ⑤ | 三线开花 | — | 5日>10日>20日均线多头排列，且三线斜率均>0 |
| ⑥ | 日线底背离 | `DIVERGENCE_DAYS`=60, `RSI_DAYS`=14 | 近60日股价创出新低，但 MACD 的 DIF 或 RSI 未创新低 |
| ⑦ | 日线低位金叉 | — | MACD 的 DIF 与 DEA 在零轴下方（均<0）金叉（前一日 DIF<DEA，当日 DIF≥DEA） |
| ⑧ | PE低估 | `VAL_YEARS`=10, `PE_PERCENTILE`=10% | 当前 PE-TTM 在近10年历史分位数≤10% 且 PE>0 |
| ⑨ | PB低估 | `VAL_YEARS`=10, `PB_PERCENTILE`=10% | 当前 PB-MRQ 在近10年历史分位数≤10% 且 PB>0 |
| ⑩ | 高股息率 | `DIV_YIELD_MIN`=3% | 最近一年现金股息（仅"实施"分红）/当前价 ≥3% |
| ⑪⑫⑬ | 深证/沪证/北证 | — | 代码以 0/3（深）、6（沪）、8/4/92（北）开头 |

**通用排除（始终生效）**：上市不满 `NEW_STOCK_DAYS`（默认365天）的次新股；名称含 ST/*ST（可关闭）、含"退"的股票。

## 筛选流程

1. 页面顶部勾选条件（可多选，**"且"关系取交集**；「全选/清空」按钮可用，已选条件附说明）；
2. 点击「🚀 开始筛选」：每个条件在独立线程中对全部股票并行计算（基于本地 SQLite，网络中断也可用），最后取交集；
3. 结果表格列：**股票名称（超链接→同花顺个股页）**、所属板块、当前价、涨跌幅、PE-TTM、触发条件列表、数据日期，
   按 **PE-TTM 由低到高**排序（无PE数据排最后），可下载 CSV。

## 数据源与兜底（本机 AKShare 1.18.94 实测）

| 数据 | 主源 | 兜底 |
| --- | --- | --- |
| 全市场快照/涨跌幅 | 新浪 `stock_zh_a_spot` | 名称代码表（价格改按最新日K计算） |
| 日K线（前复权） | 新浪 `stock_zh_a_daily` | 腾讯 `stock_zh_a_hist_tx` |
| PE-TTM / PB 历史 | 东财F10 `stock_value_em` | 百度估值（周频、自上市起） |
| 分红事件 | 巨潮 `stock_dividend_cninfo` | 新浪分红明细 |
| 上市日期 | 上交所/深交所/北交所官方列表 | — |
| 所属板块 | 申万一级行业成分 `index_component_sw` | 内置31行业代码 + 北交所官方行业兜底 |

所有请求带超时/重试/退避；单只股票失败自动跳过并计入运行日志；日志在结果页底部展开查看。
